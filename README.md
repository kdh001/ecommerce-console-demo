# 수입 원가 계산 데모

이커머스 상품 준비를 돕는 로컬 도구 `ecommerce-console`에서 원가 계산 부분을 분리한 **명령줄 데모**입니다. 상품 금액, 부피에 따른 물류비, 가상의 관세·부가세, 수수료와 기타 비용을 합산하고 개당 금액을 보여줍니다. 예제 입력은 실제 거래가 아닌 합성 숫자입니다.

## 실행 및 테스트

Python 3.11 이상만 필요합니다. 저장소 폴더에서 다음 명령을 실행하세요.

```bash
python3 demo.py
python3 -m unittest -v
```

첫 명령은 단계별 금액과 결과를 JSON으로 출력합니다. 별도 패키지 설치나 API 키는 필요하지 않습니다. 입력을 바꾸려면 `demo.py`의 `CostInput()` 인자에 계산기 필드 값을 지정할 수 있습니다.

## 범위와 한계

- 이 사본에는 원가 계산 로직만 포함됩니다. 원래 프로젝트의 웹 화면·API·관세 검색·상품 이미지 및 상세페이지·숏폼·키워드 연동은 포함되지 않습니다.
- 관세율과 비용은 예시 입력값입니다. 계산은 간소화된 모델이며, 실제 관세·세금·환급·운송비를 확정하지 않습니다. 실제 업무에는 최신 자료와 전문가 확인이 필요합니다.
- 카테고리별 실세율 자료가 없으며, 관세율을 지정하지 않으면 0으로 처리합니다. 0은 면세 판정이 아닙니다. 음수·숫자가 아닌 값·무한대 및 NaN, 수량 0, 판매가 0, 목표 마진 100% 이상과 알 수 없는 수수료 모드는 거부합니다. 계산 결과가 숫자 범위를 넘는 경우도 오류로 처리하지만, 입력값의 현실적인 적절성은 판단하지 않습니다.
- 이 사본은 합성 예제와 자동 테스트를 위한 것으로 운영 환경이나 실거래에서 검증하지 않았습니다.

## 제작 과정

원래 프로젝트는 AI의 도움을 받아 제작했습니다. 이 사본의 `cost_calculator.py`는 원본 원가 계산 코드를 발췌해 예시값과 입력 검증 등을 바꾼 것입니다. README, 데모 실행 파일과 테스트는 사본 제작 과정에서 AI가 작성했습니다. 원래 프로젝트에서 사람과 AI가 각각 맡은 구체적인 범위는 확인되지 않았습니다.
